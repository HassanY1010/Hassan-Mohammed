# Hassan Mohammed — Professional Portfolio Website

موقع شخصي احترافي عالمي للمطور ومهندس الحلول الرقمية **حسن محمد (Hassan Mohammed)**.
تم بناؤه وتطويره باستخدام أحدث معايير هندسة البرمجيات وتجربة المستخدم ليعكس هوية مهنية تقنية فاخرة ومتطورة (Premium Tech Design).

---

## 🌟 المواصفات والمميزات الرئيسية

- **التقنيات الحديثة:** Next.js 14 (App Router)، React 18، TypeScript Strict Mode، Tailwind CSS، Framer Motion، Lucide Icons.
- **تعدد اللغات الكامل (Internationalization):** دعم حقيقي ومتكامل للغتين العربية (RTL) والإنجليزية (LTR)، مع تبديل لحظي وتوجيه ديناميكي للاتجاه والخطوط والبيانات.
- **الهوية البصرية:** Dark Mode افتراضي فاخر مع درجات الأسود والفحمي العميق، وألوان الأزرق الكهربائي والسماوي (Electric Blue & Cyan)، مع صورة شخصية احترافية بهالة تقنية، وإمكانية التبديل إلى Light Mode بضغطة زر.
- **الأقسام الشاملة:**
  1. **Header & Navigation:** شريط علوي ذكي وشفاف مع تأثير Glassmorphism عند التمرير، قائمة متجاوبة كاملة للهواتف، وأزرار التبديل.
  2. **Hero Section:** قسم افتتاحي استثنائي يبرز الاسم والمسميات الوظيفية المتغيرة ديناميكياً مع الصورة الشخصية وبطاقة تيرمنال تفاعلية تعرض بنية النظام البرمجي.
  3. **About Me:** نبذة مهنية توضح رؤية حسن محمد وفلسفته الهندسية، مع بطاقات معمارية نظيفة ترتكز على مبادئ SOLID و WCAG و OWASP.
  4. **Professional Expertise:** استعراض تفصيلي لـ 8 تخصصات هندسية رئيسية مع نافذة منبثقة (Modal) تفاعلية تتيح استكشاف كافة القدرات التقنية العميقة.
  5. **Technical Skills:** تصنيف منظم للمهارات والتقنيات مع فلاتر تخصصية وبدون نسب مئوية وهمية.
  6. **Projects & Portfolio:** معرض أعمال احترافي يضم 16 مشروعاً حقيقياً ومصنفاً (SaaS, Web, Mobile, AI, UI/UX)، وبطاقات توضح المشكلة والحل والدور والتقنيات والروابط الحية.
  7. **Services:** عرض 12 خدمة تخصصية مع ميزاتها والقيمة المضافة للعميل، وزر طلب مباشر يحدد الخدمة تلقائياً في نموذج التواصل.
  8. **Work Process:** خط زمني متصل يوضح مراحل العمل السبع من الاستكشاف وحتى الصيانة والتطوير المستمر.
  9. **Contact Section:** قنوات تواصل مباشرة (WhatsApp, Email, GitHub)، ونموذج تواصل ذكي مع معالجة آمنة `/api/contact` وحماية من السبام عبر تقنية Honeypot.
  10. **CV Modal & Print:** عارض سيرة ذاتية تفاعلي بصورة شخصية وتنسيق جاهز للطباعة أو الحفظ كـ PDF مباشرة من المتصفح.
  11. **Footer:** فوتر ختامي يحتوي على روابط سريعة وحقوق الملكية الفكرية وسنة متجددة تلقائياً وزر العودة للأعلى.

## 🛡️ الأمان والأداء و SEO

- **SEO التقني:** تطبيق Next.js Metadata API، Open Graph، Twitter Cards، ملفات `robots.ts` و `sitemap.ts` الديناميكية.
- **Structured Data:** تطبيق معايير Schema JSON-LD لكل من `Person`، `WebSite`، و `ProfilePage`.
- **إمكانية الوصول (WCAG 2.2 AA):** دعم كامل للتنقل عبر لوحة المفاتيح Keyboard Navigation، روابط تخطي المحتوى، تباين لوني دقيق، وتوافق تام مع قارئات الشاشة.
- **الحماية والأمان:** ترويسات أمان صارمة في `next.config.mjs` (CSP, HSTS, X-Frame-Options, Nosniff)، وتطهير المدخلات في الـ API، وحماية من الروبوتات والـ Rate Limiting.

## 🚀 التشغيل والتطوير المحلي (Local Development)

1. تثبيت الحزم:
```bash
npm install
```

2. تشغيل السيرفر المحلي:
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

3. فحص الأنواع (Type-check):
```bash
npx tsc --noEmit
```

4. إنشاء نسخة الإنتاج (Production Build):
```bash
npm run build
```

## ☁️ النشر على Vercel (Deployment)

المشروع مهيأ بالكامل للنشر الفوري بنقرة واحدة على منصة Vercel:
1. ارفع الكود إلى مستودع GitHub الخاص بك: `https://github.com/HassanY1010/portfolio`
2. سجّل الدخول إلى [Vercel](https://vercel.com) واختر **Import Project**.
3. اختر المستودع واضغط **Deploy**.
4. سيتم بناء الموقع ونشره عالمياً على شبكة Vercel Edge Network مع تفعيل شهادة SSL وتحديثات سريعة عند أي تعديل.
